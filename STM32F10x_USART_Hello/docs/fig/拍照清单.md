# 实验报告配图清单（把截图/照片按下面的文件名放到本文件夹里即可）

> 报告正文已经写好（`docs\实验报告.md`）。等你把下面 9 张图放进 `docs\fig\` 文件夹，
> 我就能一键生成带图的 PDF，并打包成提交用的 ZIP。
>
> 文件名**必须一致**（大小写不敏感），后缀 `.png` / `.jpg` 都行。

| 文件名 | 拍/截什么 | 怎么弄 |
|---|---|---|
| `fig1_cubemx_mcu.png` | CubeMX 里选中 STM32F103C8Tx | 打开 CubeMX → New Project → Part Number 搜 STM32F103C8 → 截图 |
| `fig2_cubemx_pinout.png` | 引脚配置界面（能看到 PA9/PA10 标着 USART1_TX / USART1_RX） | CubeMX → Pinout & Configuration → 点 USART1 后截图 |
| `fig3_usart_params.png` | USART1 参数设置 | 同上一页，把下面 Parameter Settings 里的 115200/8/1/None 和 NVIC 勾选一起截进来 |
| `fig4_cubemx_clock.png` | 时钟树 72MHz | Clock Configuration 选项卡截图 |
| `fig5_wiring.jpg` | 实物接线照片 | 手机拍：STM32 + USB转TTL 的接线（要能看清 PA9/PA10/GND 三根线） |
| `fig6_task1_nodelay.png` | 任务1：不加延时 | 烧录后开串口助手，等它刷屏几秒，屏幕出现卡顿/行不完整时截图 |
| `fig7_task1_delay.png` | 任务1：加 100ms 延时后 | 把 main.c 里 `SEND_DELAY_MS` 改成 `100U` 重新编译烧录，稳定刷屏时截图 |
| `fig8_task2_pause.png` | 任务2：发 `#` 后暂停 | 先让它正常刷，然后发 `#`，等接收区停住后截图（截图里最好能看到发送框里的 `#`） |
| `fig9_task2_resume.png` | 任务2：发 `*` 后恢复 | 紧接上一步发 `*`，恢复刷屏后截图 |

## 小提示

- 截图时尽量把**串口助手的参数栏**（COM口 / 115200 / 8 / 1 / None）也一起截进去，更有说服力；
- `fig5_wiring.jpg` 如果暂时不方便拍，可以先跳过，报告照样能用（我会保留说明文字）；
- 图放好后跟我说一声，我立刻生成 `实验报告.pdf` 和提交用的 ZIP。
