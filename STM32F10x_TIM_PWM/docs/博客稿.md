# STM32 定时器入门：从 2 秒闪灯到 PWM 呼吸灯，顺便用 Keil 虚拟示波器看波形

> 定时器是 STM32 里最容易"用错时钟"的外设。这篇把 PSC/ARR 的算法、定时中断闪灯、PWM 呼吸灯一次讲清楚，最后用 Keil 自带的逻辑分析仪验证波形。

## 一、先把定时器的账算清楚

STM32F103 的 TIM2~TIM5 是 16 位通用定时器，核心是一个"分频 + 计数"的时基单元：

```
TIMxCLK ──▶ PSC 预分频 ──▶ CK_CNT ──▶ CNT 计数 0→ARR ──▶ 溢出（更新事件）
```

三个寄存器就够了：

| 寄存器 | 作用 |
|---|---|
| **PSC** | 预分频，`f_CNT = f_TIM / (PSC+1)` |
| **ARR** | 自动重装载，计到 ARR 归零并产生更新事件 |
| **CCR** | 比较值，PWM 模式下决定占空比 |

定时时间：

```
T = (PSC+1) × (ARR+1) / f_TIM
```

**第一个坑**：TIM3 挂在 APB1 上。APB1 分频是 2，PCLK1 = 36 MHz，但 **APB1 分频≠1 时，定时器时钟 = 2 × PCLK1 = 72 MHz**。按 36 MHz 算，定时时间会差一倍。

## 二、任务一：定时中断，2 秒一个亮灭周期

要求 LED 亮 1 s、灭 1 s，所以让定时器**每 1 秒**进一次更新中断，在中断里翻转 LED 就行。

取计数频率 10 kHz：

```c
PSC = 72 000 000 / 10 000 - 1 = 7199;
ARR = 10 000 - 1 = 9999;      /* 10 kHz / 10000 = 1 Hz */
```

```c
htim3.Instance = TIM3;
htim3.Init.Prescaler   = 7200 - 1;
htim3.Init.Period      = 10000 - 1;
htim3.Init.CounterMode = TIM_COUNTERMODE_UP;
HAL_TIM_Base_Init(&htim3);

HAL_TIM_Base_Start_IT(&htim3);        /* 启动更新中断 */

void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim)
{
    if (htim->Instance == TIM3)
        HAL_GPIO_TogglePin(GPIOC, GPIO_PIN_13);   /* 板载 LED */
}
```

**为什么不用 HAL_Delay？** 因为 `HAL_Delay` 是死等，CPU 被占住、而且时间受其他代码影响；定时器中断由硬件计时，到点才进来一下，精度和效率都高得多。

> 板载 PC13 是**共阳接法、低电平点亮**，所以初始化时输出高电平表示"熄灭"。

## 三、任务二：PWM 呼吸灯

PWM 模式 1 的规则很简单：

```
CNT < CCR  → 输出高
CNT ≥ CCR  → 输出低
```

于是：

```
占空比 = CCR / (ARR+1)
频率   = f_TIM / ((PSC+1)(ARR+1))
```

想要 1 kHz 的 PWM（远高于人眼闪烁频率，灯看起来是"连续"的）：

```c
PSC = 72 MHz / 1 MHz - 1 = 71;
ARR = 1 MHz / 1 kHz - 1 = 999;
```

```c
htim3.Init.Prescaler = 72 - 1;
htim3.Init.Period    = 1000 - 1;
HAL_TIM_Base_Init(&htim3);
HAL_TIM_PWM_Init(&htim3);

TIM_OC_InitTypeDef sConfigOC = {0};
sConfigOC.OCMode     = TIM_OCMODE_PWM1;
sConfigOC.Pulse      = 0;
sConfigOC.OCPolarity = TIM_OCPOLARITY_HIGH;
HAL_TIM_PWM_ConfigChannel(&htim3, &sConfigOC, TIM_CHANNEL_1);

HAL_TIM_PWM_Start(&htim3, TIM_CHANNEL_1);   /* PA6 = TIM3_CH1 */
```

**呼吸**就是让 CCR 慢慢来回走：

```c
while (1) {
    for (uint16_t i = 0; i <= 999; i++) {          /* 渐亮 1 s */
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, i);
        HAL_Delay(1);
    }
    for (uint16_t i = 999; i > 0; i--) {           /* 渐灭 1 s */
        __HAL_TIM_SET_COMPARE(&htim3, TIM_CHANNEL_1, i);
        HAL_Delay(1);
    }
}
```

1000 级 × 1 ms × 2 = **2 秒一个完整呼吸周期**，占空比分辨率 0.1%，肉眼看非常平滑。

## 四、没有示波器？用 Keil 的逻辑分析仪

```
① 魔术棒 → Debug → 选 Use Simulator
② Ctrl+F5 进仿真
③ View → Analysis Windows → Logic Analyzer
④ Setup → New，信号名填 PORTA.6，Display Type 选 Bit
⑤ F5 运行
```

> 信号名必须写 **`PORTA.6`**。写成 `GPIOA.ODR.6` 或 `TIM3_CH1`，Keil 都会提示 Unknown Signal。

波形上能看到：

- **周期约 1 ms**（1 kHz），与 `72 MHz / (72 × 1000)` 完全一致；
- **高电平宽度随时间缓慢变化**：从几乎全低（最暗）→ 逐渐变宽（变亮）→ 再变窄（变暗）；
- 一个"宽窄循环"约 **2 s**，正好对应程序里的 1000 步 × 1 ms × 2。

## 五、踩过的坑

| 现象 | 原因 | 解决 |
|---|---|---|
| 定时时间差一倍 | 把 TIM3 时钟按 36 MHz 算了 | 用 **72 MHz**（APB1 分频≠1 时定时器时钟 ×2） |
| LED 一直不亮 | PC13 共阳，高电平是"灭" | 初始输出高，翻转即可 |
| PA6 没有波形 | 忘了配复用推挽 | MSP 里 `GPIO_MODE_AF_PP` + 开 TIM3 时钟 |
| 呼吸灯有频闪 | PWM 频率太低（100 Hz） | 提到 1 kHz 以上 |
| 呼吸不平滑 | 步进太大或延时太长 | 1000 级、每 1 ms 一步 |
| 仿真看不到信号 | 信号名写错 | 用 `PORTA.6` |

---

## 小结

定时器看着寄存器多，其实就三件事：**PSC 定快慢、ARR 定周期、CCR 定占空比**。把 `T = (PSC+1)(ARR+1)/f_TIM` 和 `占空比 = CCR/(ARR+1)` 这两个式子记牢，闪灯、呼吸灯、舵机、电机调速都是同一套东西。

至于示波器 —— Keil 的逻辑分析仪已经把周期和占空比都量出来了，**1 ms / 1 kHz，占空比按 2 s 周期变化**，和算出来的完全对得上。
